# Habilidad: Diseño y Optimización de Miniaturas (Imágenes)

Esta skill reúne los principios de composición visual, psicología del espectador y optimización según los estándares de alto CTR (puntuación vidIQ 85+).

---

## 1. Reglas Innegociables de Composición (vidIQ Scorer 85+)

1. **Un Solo Elemento de Choque (Foco Único):**
   - El ojo humano tiene solo 0.05 a 0.3 segundos para escanear la miniatura en móvil.
   - El objeto principal (héroe) debe ocupar el centro o plano medio con máxima nitidez.
   - **El fondo nunca compite:** Debe estar desenfocado (bokeh), desaturado o en tonos planos oscuros. Las texturas (grietas, agua, humo) son textura ambiental, nunca personajes.
2. **Máximo 3 Palabras:**
   - Textos más largos se vuelven una mancha ilegible a escala de pantalla de celular.
   - Tipografía ultra-gruesa (Montserrat Black, Bebas Neue, Impact) con alto contraste.
   - Paleta de texto: Blanco puro como base + **Rojo o Amarillo Neón como único acento de choque**.
3. **Vector Diagonal de Lectura:**
   - Apilar el texto creando una flecha visual implícita hacia el objeto principal.
   - La palabra clave en rojo/acento debe dirigir el ojo hacia el elemento de tensión.
4. **Complementariedad con el Título:**
   - La miniatura nunca repite palabras del título. Si el título ya dice un término ("2027", "político", "comida"), la miniatura tiene prohibido usarlo.
   - La miniatura abre o amplifica la brecha de curiosidad (*curiosity gap*).
5. **Aislamiento de Variables en Tests A/B:**
   - Para probar dos variantes de un mismo video (ej. Agua vs Sequía), el bloque tipográfico debe ser idéntico en corte de renglón, posición y fuente. Solo cambia el concepto visual.
